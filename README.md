# ChessArrow-Maia

Maia chess engine model files for ChessArrow, distributed as KeyAuth files
(KeyAuth entries point at the release download links below).

Release `maia-v1` assets:
- Lc0 weights: maia-1100.pb.gz ... maia-1900.pb.gz
- Maia-3 ONNX (fp16): maia3-5m.fp16.onnx, maia3-23m.fp16.onnx, maia3-79m.fp16.onnx

Models are from the Maia chess project (CSSLab/maia-chess, bqrio/maia3-onnx).
